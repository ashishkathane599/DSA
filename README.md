# 🐍 Python Data Structures Repository

Welcome to my **Python Data Structures** repository!  
This repo contains implementations of major data structures in Python, built from scratch for **learning, practice, and interview preparation**.

---

## 📌 Topics Covered

### 1. Arrays
- Static and dynamic arrays
- Common operations (insert, delete, search, traverse)

### 2. Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Circular Doubly Linked List
- Operations: insert (beginning, end, specific position), delete, search, display

### 3. Stacks
- Stack using arrays
- Stack using linked lists
- Common operations: push, pop, peek

### 4. Queues
- Simple Queue
- Circular Queue
- Priority Queue
- Queue using linked lists

### 5. Trees 🌳
- Binary Tree
- Binary Search Tree (BST)
- Tree Traversals: Inorder, Preorder, Postorder
- AVL Trees (if implemented)
- Heap (Min Heap, Max Heap)

### 6. Graphs
- Graph representation (Adjacency List, Adjacency Matrix)
- BFS (Breadth First Search)
- DFS (Depth First Search)
- Dijkstra's Algorithm (if implemented)
